# Get it running

0. Create a Python venv (optional, but highly recommended)
1. Install requirements with pip `install -r requirements.txt`
2. Start up the demo with python3 demo.py
3. Go to http://localhost:5000
4. Use inspect elements to and use "Responsibe Design Mode" ( ctrl+alt+m shortcut with Firefox )

There is also a demo video available in YouTube: https://youtu.be/542FxKqPhOQ
